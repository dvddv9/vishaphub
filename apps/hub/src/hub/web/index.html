how it works

One plan, three jobs, one verdict

  1. 1

    Generate

    The model proposes code from your spec. It proposes; it never decides.

  2. 2

    Validate

    Six checks compare the code with the promise: structure, syntax, contract, coverage, behavior, conformance.

  3. 3

    Analyse

    The analyser checks whether the code is dangerous. Every finding is named, with its source.

The strictest verdict wins. Whatever was not checked is listed, not hidden.
