# Contributing to VishapHub

Спасибо за интерес. Правила простые и проверяемые.

## Как запустить

```bash
cd apps/hub
pip install -e .[full]
PYTHONPATH=src python -m pytest -q
PYTHONPATH=src python -m ruff check src tests
```

`hub` — stdlib без внешних зависимостей: сервер, магазин прогонов, лимиты, шаблоны. Всё,
что требует Postgres, живёт в `teamstore.py` и включается переменной окружения.

## Как предложить изменение

1. Создайте Issue: какую проблему решает, как проверено.
2. Ветка: `git checkout -b feat/short-name`. В `main` не пушим.
3. Меняете — прогоняете тесты. Зелёный набор без новых `skipped` — условие, а не пожелание.
4. PR: что изменено, чем проверено, что осталось незакрытым.

## Стиль

- Python 3.11+, стандартная библиотека первой. Новая зависимость — отдельный разговор с
  причиной, почему без неё нельзя.
- `ruff check` чистый. Строка — до 110 символов.
- Комментарий объясняет «почему», а не «что»: код говорит «что» сам.
- Коммит: `hub: что изменилось` — одной строкой, без точки в конце.
- Тест проверяет поведение, а не реализацию: падает, если убрать защиту, и говорит, какая.
