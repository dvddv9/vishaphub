Vishap is a SaaS platform for automated security analysis of engineering
materials — source code, configuration files, specifications, logs and structured
data. You give it a file; it returns a report you can act on.

Most security tooling forces a choice. Rule-based scanners are precise but blind
to anything nobody wrote a rule for. A general-purpose chat model reads broadly
but produces prose you cannot file as evidence. Vishap runs both and keeps the
results separate: deterministic SAST/SCA findings on one side, model reasoning on
the other, synthesised into one document.

Each report contains:

- **Findings** mapped to CWE and OWASP Top 10, with severity and the function or
  file they point at.
- **A STRIDE threat model** derived from those findings rather than from a
  generic checklist.
- **Refactoring options** with effort estimates in days, so the report can go
  into planning as-is.
- **An audit trail** with a SHA-256 hash of the analysed slice, the provenance
  commit, and PII-redaction flags.

The report is deliberately honest about confidence. When something looks wrong
but cannot be proven from the material, it says so and asks for a human review
instead of asserting a vulnerability. That is why reports end in
`REQUIRES_REVIEW` more often than in a clean `SAFE`.

Vishap is available as a web app, a CLI, an HTTP API and a GitHub App. The
CLI exits non-zero when a quality gate fails, so it drops into a CI pipeline
without parsing output. The GitHub App comments on pull requests.
