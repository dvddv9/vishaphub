# Contributing to Vishap

Спасибо за интерес к проекту! Мы рады любому вкладу.

## Как сообщить о баге
1. Проверьте, не создан ли уже такой Issue.
2. Создайте новый Issue, используя шаблон «Bug report».
3. Опишите шаги для воспроизведения, ожидаемое и фактическое поведение.

## Как предложить фичу
1. Создайте Issue с шаблоном «Feature request».
2. Опишите, какую проблему это решит.

## Как отправить Pull Request
1. Форкните репозиторий.
2. Создайте ветку: `git checkout -b feature/my-feature`.
3. Внесите изменения.
4. Убедитесь, что тесты проходят: `pytest tests/`.
5. Отправьте PR, заполнив шаблон.

## Стиль кода
- Python: следуйте PEP 8. Используйте `ruff check src/` для линтинга.
- Коммиты: пишите осмысленные сообщения (например, `feat: add new detector`).

## Лицензия
Отправляя PR, вы соглашаетесь с тем, что ваш вклад будет распространяться под лицензией AGPL-3.0-or-later.
