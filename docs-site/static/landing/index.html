What you get back

One report per run. The verdict is on top, so you can read it in five seconds or hand it to a pipeline.

Verdict
SAFE or REQUIRES_REVIEW. With vishap analyze --gate the command exits with 1 when a review is needed.
Risks
Every finding with its CWE, a priority from critical to low, and a short note.
Runbook
Immediate, short-term and long-term steps for each weakness found, and who to escalate to.
Audit trail
A SHA-256 of the material, PII and compliance flags, and a valid-until date, so a report can be checked later.
Exports
SARIF 2.1.0 for GitHub Code Scanning, and a CycloneDX SBOM.
Where it runs
In the web app, the command line, the REST API (including async jobs) and a GitHub App for pull requests.

How a run goes

  1. Paste or upload

    Code, a config, an API spec, a log or plain data. Up to 200,000 characters.

  2. Run the analysis

    Rules run first, then the six LLM stages. A full run takes 30 to 90 seconds.

  3. Read the report

    Verdict first, then risks, runbook and audit trail.

Pick how it runs

The model is your choice. What differs is the key you need and where your material goes.

EngineKeyWhere your material goes
Claude default Anthropic API key To Anthropic, after PII redaction.
Groq, DeepSeek, OpenAI, OpenRouter The provider’s key To the provider you pick, after PII redaction.
Local model (Ollama) None Stays on your machine. Available when you run Vishap yourself.
Analysis without LLM None Stays on the Vishap server. Built-in rules only, no model, instant.

The public demo uses the server’s own Claude key. A self-hosted install uses whichever engine you configure.

Run it yourself

Vishap is open source. You need these installed first:

  • Python 3.11 or newer
  • Node.js 18 or newer, for the web app
  • PostgreSQL 16, for history and the audit trail
  • Git
git clone https://github.com/dvddv9/vishap
cd vishap
pip install -r requirements.txt
cp .env.example .env    # add your LLM key, or set VISHAP_DEV=true
python -m src.main

The API starts on port 8080. The full steps are in the getting started guide.
